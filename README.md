## 📖 Overview

This project is a Student Information System developed using HTML and JavaScript. It manages student records, displays student information dynamically, calculates grades, evaluates attendance status, and computes average marks.

The project was created to practice core JavaScript concepts such as Objects, Arrays, Functions, Loops, Event Handling, and DOM Manipulation.

---

## 🚀 Features

* Store student information using JavaScript objects
* Manage multiple students using arrays
* Display student records dynamically
* Show student details on button click
* Calculate grades based on marks
* Evaluate attendance status
* Add new student records using `push()`
* Calculate average marks
* Use loops (`for` and `forEach`) for data processing
* Practice DOM manipulation and event handling

## 📋 Functionality

### Student Records

The project stores student information such as:

* Student ID
* Name
* College
* Attendance
* Course
* Stream
* Project Type
* Marks

### Grade Evaluation

| Marks        | Grade   |
| ------------ | ------- |
| 90 and above | A Grade |
| 70 - 89      | B Grade |
| 35 - 69      | C Grade |
| Below 35     | Failed  |

### Attendance Evaluation

| Attendance   | Status             |
| ------------ | ------------------ |
| 90 and above | High Attendance    |
| 50 - 89      | Average Attendance |
| 35 - 49      | Low Attendance     |
| Below 35     | Debar              |
